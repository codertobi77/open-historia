Open Historia / Guide de configuration IA

Connectez votre IA

Débloquez la diplomatie IA, les événements historiques générés dynamiquement et un conseiller stratégique en connectant n'importe quel fournisseur d'IA — des modèles locaux gratuits aux API cloud premium.

Ce que l'IA alimente dans Open Historia

Diplomatie IA — négociez avec n'importe quelle nation via un chat en langage naturel
Briefings de renseignement IA — obtenez des synthèses sur le statut de n'importe quel pays
Événements générés par IA — événements dynamiques façonnés par vos décisions et l'état du monde
Conseiller IA — consultez-le pour des orientations stratégiques, des analyses économiques et la planification de guerre
Résolution de combat IA — batailles résolues par l'IA selon la force des troupes, le terrain et la stratégie

Comment ça marche

Open Historia prend en charge plusieurs types de fournisseurs d'IA depuis un seul panneau de paramètres. Vous pouvez passer de l'un à l'autre à tout moment :

  • Gemini — l'API native de Google, avec un niveau gratuit généreux
  • OpenAI — les modèles officiels GPT-4o, GPT-4.1 et série o
  • Anthropic — Claude via l'API Messages
  • NVIDIA NIM — les modèles hébergés par NVIDIA sur build.nvidia.com
  • Compatible OpenAI — toute API qui parle le protocole /v1/chat/completions (Ollama, LM Studio, llama.cpp, DeepSeek, Groq, Together.ai, OpenRouter et plus)
  • Compatible Anthropic — tout proxy auto-hébergé qui parle l'API Messages d'Anthropic
  • NVIDIA NIM (compatible OpenAI) — un point d'accès NIM auto-hébergé ou d'entreprise via le protocole compatible OpenAI

Les appels IA partent directement de votre navigateur vers le fournisseur, de sorte que votre clé API n'atteint jamais un serveur tiers. Gemini et l'API native d'Anthropic autorisent explicitement les appels depuis le navigateur. Pour les backends auto-hébergés qui n'envoient pas d'en-têtes CORS (comme Ollama), configurez les origines autorisées côté backend — le guide ci-dessous explique comment.

Options de configuration des fournisseurs

Google Gemini (niveau gratuit disponible)

Gemini est le fournisseur par défaut et le moyen le plus simple de démarrer. Google propose un niveau gratuit sur Google AI Studio largement suffisant pour jouer en solo.

Obtenir une clé API

Rendez-vous sur Google AI Studio, connectez-vous avec un compte Google et cliquez sur « Create API Key ». C'est gratuit — aucune configuration de facturation requise.

Choisir le modèle

Le modèle par défaut fonctionne très bien dès le départ. Dans les paramètres, le sélecteur de modèle liste tous les modèles Gemini disponibles pour votre clé — choisissez-en un autre pour un raisonnement plus poussé (vérifiez les limites de débit du niveau gratuit).

Configurer dans Open Historia

Dans les paramètres du jeu, sélectionnez Gemini comme fournisseur et collez votre clé API. Aucune URL de point d'accès nécessaire.

OpenAI (GPT-4o, GPT-4.1, série o)

Utilisez l'API officielle d'OpenAI pour GPT-4o, GPT-4.1 ou les modèles de raisonnement de la série o. Nécessite un compte API payant avec des crédits préchargés.

Obtenir une clé API

Inscrivez-vous sur platform.openai.com, ajoutez un moyen de paiement et créez une clé API dans « API Keys ».

Choisir un modèle

gpt-4.1-mini est rapide et économique, gpt-4.1 gère la diplomatie complexe, et o4-mini excelle au raisonnement stratégique.

Configurer dans Open Historia

Sélectionnez OpenAI comme fournisseur, collez votre clé API et spécifiez éventuellement un modèle. Le point d'accès est préconfiguré.

Anthropic Claude

Utilisez Claude d'Anthropic via l'API Messages. Réputé pour son écriture nuancée et son bon suivi des instructions — excellent pour une diplomatie immersive et une génération d'événements riche.

Obtenir une clé API

Inscrivez-vous sur console.anthropic.com et générez une clé API.

Choisir un modèle

claude-sonnet-4-20250514 offre le meilleur équilibre qualité/vitesse. claude-haiku-3-5-20241022 est plus rapide et moins cher.

Configurer dans Open Historia

Sélectionnez Anthropic comme fournisseur et collez votre clé API. Accès direct depuis le navigateur.

DeepSeek

DeepSeek propose des modèles puissants à très bas coût. Leur API est compatible OpenAI, elle fonctionne donc via l'option de fournisseur « Compatible OpenAI ».

Obtenir une clé API

Inscrivez-vous sur platform.deepseek.com, rechargez des crédits (minimum 2 $) et créez une clé API.

Définir le point d'accès

L'URL de base de l'API DeepSeek est https://api.deepseek.com/v1. Le modèle deepseek-chat couvre la plupart des besoins ; deepseek-reasoner est disponible pour le raisonnement stratégique complexe.

Configurer dans Open Historia

Sélectionnez Compatible OpenAI comme fournisseur. Définissez le point d'accès sur https://api.deepseek.com/v1, saisissez votre clé API et définissez le modèle sur deepseek-chat.

LLM locaux (gratuits & privés)

Faites tourner des modèles entièrement sur votre propre matériel. Pas de clé API, pas d'internet requis après le téléchargement, totalement privé. Utilisez le fournisseur Compatible OpenAI dans les paramètres.

Ollama (recommandé pour la configuration la plus simple)

Ollama est le moyen le plus simple de faire tourner des LLM localement. Fonctionne sur Windows, macOS et Linux.

Installer Ollama

Téléchargez depuis ollama.com et installez.

Récupérer un modèle

ollama pull llama3.2 — ou tout modèle de votre choix. Recommandés : llama3.2 (léger), mistral (équilibré), qwen2.5 (raisonnement solide).

Configurer dans Open Historia

Sélectionnez Compatible OpenAI, définissez le point d'accès sur http://localhost:11434/v1. Aucune clé API nécessaire pour un usage local. Démarrez Ollama avec OLLAMA_ORIGINS défini sur l'adresse du site pour autoriser les appels depuis le navigateur.

LM Studio (orienté interface graphique)

LM Studio fournit une interface graphique pour télécharger et exécuter des modèles. Idéal pour les utilisateurs Windows et macOS qui préfèrent une interface graphique.

Installer LM Studio

Téléchargez depuis lmstudio.ai.

Télécharger un modèle

Utilisez le navigateur de modèles intégré pour rechercher et télécharger un modèle (par ex. Llama 3.2, Mistral 7B, Phi-3).

Démarrer le serveur local

Allez dans l'onglet « Local Server », chargez votre modèle et cliquez sur « Start Server ». L'URL par défaut est http://localhost:1234/v1.

Configurer dans Open Historia

Sélectionnez Compatible OpenAI, définissez le point d'accès sur http://localhost:1234/v1. Aucune clé API nécessaire.

llama.cpp (performance maximale)

llama.cpp est l'option la plus performante pour les utilisateurs techniques. Exécute des modèles au format GGUF avec un minimum de surcharge.

Compiler le serveur llama.cpp

Suivez les instructions de compilation pour votre plateforme.

Télécharger un modèle GGUF

Récupérez un modèle GGUF depuis Hugging Face (par ex. Llama-3.2-3B-Instruct-Q4_K_M.gguf).

Démarrer le serveur

./llama-server -m model.gguf --port 8080

Configurer dans Open Historia

Sélectionnez Compatible OpenAI, définissez le point d'accès sur http://localhost:8080/v1.

Autres API cloud (compatibles OpenAI)

Tout service cloud qui parle le protocole OpenAI chat completions fonctionne via le fournisseur Compatible OpenAI. Options populaires :

Service URL du point d'accès Remarquable
Groq https://api.groq.com/openai/v1 Inférence rapide, niveau gratuit généreux
Together.ai https://api.together.xyz/v1 Large choix de modèles, 1 $ de crédit gratuit
OpenRouter https://openrouter.ai/api/v1 Accès à plus de 300 modèles via une seule API
DeepInfra https://api.deepinfra.com/v1/openai Modèles open source, paiement au jeton
Fireworks https://api.fireworks.ai/inference/v1 Rapide, inférence GPU serverless

Pour chacun d'entre eux, sélectionnez Compatible OpenAI, collez l'URL du point d'accès et votre clé API de ce service, et définissez le nom du modèle.

Dépannage

Les fonctionnalités IA sont grisées ou ne répondent pas

Assurez-vous que votre fournisseur est configuré correctement. Pour les API cloud, vérifiez que votre clé API est valide et dispose de crédits. Pour les backends locaux, vérifiez que le serveur fonctionne et que l'URL du point d'accès correspond. Le jeu vérifie la connectivité au chargement — si le backend est injoignable, les fonctionnalités IA ne s'activeront pas.

La clé API ne fonctionne pas

Vérifiez que vous avez sélectionné le bon fournisseur dans les paramètres. Une clé Gemini ne fonctionne pas avec le fournisseur OpenAI, et inversement. Pour les fournisseurs compatibles OpenAI, assurez-vous que l'URL du point d'accès inclut le chemin de base complet (par ex. https://api.deepseek.com/v1, pas seulement https://api.deepseek.com).

Les réponses de l'IA sont lentes

Pour les modèles locaux : essayez un modèle plus petit (3 milliards de paramètres) ou activez l'accélération GPU. Ollama et LM Studio prennent tous deux en charge le déchargement GPU. Pour les API cloud : les modèles plus lents comme GPT-4.1 ou Claude Sonnet produisent une meilleure qualité mais prennent plus de temps — essayez un modèle plus rapide si la latence pose problème. Groq est particulièrement rapide pour l'inférence cloud.

Erreurs CORS avec un backend distant

Les appels IA partent directement de votre navigateur vers le fournisseur. Gemini et Anthropic autorisent les appels depuis le navigateur. Si vous voyez des erreurs CORS avec un backend auto-hébergé (Ollama, LM Studio), configurez-le pour autoriser l'origine du site — par exemple, démarrez Ollama avec OLLAMA_ORIGINS défini sur l'adresse du site.

DeepSeek / OpenRouter renvoie des erreurs

Ces services utilisent le fournisseur Compatible OpenAI. Assurez-vous que l'URL du point d'accès est correcte et inclut /v1. Le nom du modèle doit correspondre exactement à ce que le service attend (par ex. deepseek-chat pour DeepSeek, ou le slug complet OpenRouter comme openai/gpt-4.1).
